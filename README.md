# KamRai (กำไร)

เครื่องมือฟรีสำหรับพ่อค้าแม่ค้าออนไลน์ — รู้ว่า **ขายแล้วได้กำไรจริงเท่าไหร่** และเห็นภาพรวมร้านในหน้าเดียว

> 🔒 **ข้อมูลร้านคุณไม่ออกจากเครื่องคุณ** — ทุกอย่างคำนวณในเบราว์เซอร์ ไม่มีเซิร์ฟเวอร์เก็บข้อมูล

## สถานะ

🚧 กำลังวางแผน — ยังไม่มีเวอร์ชันให้ใช้

## สิ่งที่จะทำ (MVP)

- **เครื่องคิดราคา** — กรอกต้นทุน ค่าส่ง ค่ากล่อง เลือกแพลตฟอร์ม → รู้ราคาขั้นต่ำที่ไม่ขาดทุน และราคาที่ได้กำไรตามเป้า
- **ภาพรวมร้านจากไฟล์ CSV** — ยอดขาย กำไรจริง สินค้าที่ทำกำไรดี/แย่สุด อัตราตีกลับ · ใช้ได้กับไฟล์จากหลายแพลตฟอร์ม

## หลักการ

ฟรี · ไม่ต้องสมัคร · ภาษาไทย · ใช้บนมือถือได้ · ข้อมูลอยู่ในเครื่องผู้ใช้เท่านั้น
